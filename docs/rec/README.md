# rec/ — video explicativo

Este directorio contiene el video asciinema de **Fogón · pedidos y reparto, de V1 a V2** y el reproductor
que se usa en la página del proyecto.

- `fogon.cast`: grabación original (asciicast v2).
- `fogon.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:54. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
